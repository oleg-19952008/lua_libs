# Terminal Pong

Терминальная игра «Пинг-Понг» на Lua, построенная поверх библиотек этого репозитория.

## Зависимости (из корня репозитория)

| Библиотека   | Использование в игре |
|--------------|----------------------|
| `color.lua`  | Генерация ANSI TrueColor SGR-кодов для фреймбуфера (`bgRGB`/`fgRGB`), цветной финальный текст |
| `paths.lua`  | Разрешение путей к скриптам и файлу рекордов (`joinPath`) |
| `random.lua` | Инициализация ГСЧ (`initRandom`) и случайные байты для направления/угла подачи мяча |
| `base64.lua` | Кодирование строки результата перед записью в `score.dat` |

## Файлы

- `main.lua` — точка входа: цикл игры, ввод, рендер, сохранение рекордов.
- `game.lua` — чистая игровая логика (физика мяча, столкновения, ИИ, счёт). Легко тестировать без терминала.
- `term.lua` — терминальная графика: RGB-буфер + вывод через color.lua.
- `input.lua` — неблокирующий ввод (LuaJIT `poll()`; фолбэк — чтение строк).

## Запуск

```sh
lua main.lua          # Lua 5.1–5.4 / LuaJIT
luajit main.lua       # рекомендуется: включает raw-режим и sleep через ffi
```

Нужен терминал с поддержкой ANSI TrueColor и alternate screen (Windows Terminal, iTerm2, kitty, modern gnome-terminal и т.п.).

## Управление

| Клавиша | Действие |
|---------|----------|
| `Space` | старт / рестарт после конца матча |
| `W` / `S` или `↑` / `↓` | движение левой ракетки |
| `P` | пауза |
| `Q` | выход |

До 7 очков — победа. После каждого удара о ракетку мяч ускоряется, угол отскока зависит от точки попадания.

Результат матча сохраняется в `score.dat` (строка base64: `дата|счёт|W/L`).
