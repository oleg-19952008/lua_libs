# pong — терминальная игра на Lua

Pong с RGB-графикой в консоли. Использует библиотеки репозитория:
`color.lua` (TrueColor SGR-коды), `paths.lua`, `random.lua` (сид + случайная подача),
`base64.lua` (запись результата в score.dat).

## Файлы
| файл | назначение |
|---|---|
| `main.lua` | точка входа, игровой цикл, рекорды |
| `game.lua` | логика: мяч, ракетки, ИИ, счёт |
| `term.lua` | RGB-буфер 64×22 + ANSI TrueColor рендер (diff, run-length) |
| `font.lua` | встроенный битмап-шрифт 5×7 — текст рисуется «пикселями» |
| `input.lua` | неблокирующий ввод (Console API / stty+poll / строковый фолбэк) |
| `winapi.lua` | обёртка kernel32 через ffi: raw-режим, ReadConsoleInputA, Sleep |

## ⚠️ Важно: чем запускать

**Запускай через LuaJIT**, а не `lua5.1.exe`:

```
luajit main.lua
```

Если запустить обычную **Lua 5.1.4 из дистрибутива `lua-5.1.5_Win64_bin.zip`**
(`lua5.1.exe main.lua`), она **не содержит FFI**, поэтому неблокирующий ввод
через Console API недоступен. Игра переключается в fallback-режим:
она читает ввод построчно (`io.read`) и каждый кадр перерисовывает всё поле
сплошь потоком длинных escape-последовательностей `\x1b[48;2;r;g;b;30m ...`
(это видно как «←[?1049h ←[48;2;...» в выводе, если терминал не интерпретирует
ANSI, например при перенаправлении в pipe). Терминал при этом мигает,
ракетки двигаются только после Enter, а CPU грузится busy-wait'ом.

### Почему LuaJIT
- `ffi` → `winapi.lua` включает raw-режим консоли (`SetConsoleMode`),
  читает нажатия клавиш мгновенно без Enter (`ReadConsoleInputA`)
  и использует `Sleep()` вместо кручения CPU;
- рендер становится точечным (обновляются только изменившиеся пиксели).

### Альтернативы, если нет LuaJIT
1. Собрать/скачать **Lua 5.1.5** (а не 5.1.4 из архива) + [`luabit`](http://luaforge.net/projects/bit/) —
   но полноценного raw-ввода на plain Lua 5.1 в Windows всё равно не будет
   (нет доступа к Console API без расширения).
2. Play с fallback-режимом: управление — набрать `w`/`s`/`space`/`q` и нажать Enter.

## Управление
- `W`/`S` или стрелки ↑/↓ — ракетка
- `Space` — старт / рестарт
- `P` — пауза
- `Q` — выход

## Запуск
```sh
cd pong
luajit main.lua        # рекомендуемый способ (Windows/Linux/macOS)
```
Требования: терминал с TrueColor (Windows Terminal, ConEmu, mintty, любой xterm-24bit).
Рекорды пишутся в `score.dat` (base64-строки).
